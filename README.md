# 📸 Pinterest Ideal
Segunda parte do projeto 

O **Pinterest Ideal** é um aplicativo Android inspirado no Pinterest, desenvolvido como projeto acadêmico. Ele funciona como uma galeria de imagens onde os usuários podem compartilhar fotos do próprio celular e visualizar as galerias de outros usuários e amigos.

## ✨ Funcionalidades

- 🖼️ Visualização de galerias de imagens.
- 📱 Upload de fotos do celular.
- 👥 Pesquisa e interação com outros usuários e amigos.
- 📁 Criação de pastas para organizar imagens.
- 💬 Tela de mensagens.

## 🛠️ Tecnologias utilizadas

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Navigation Compose

## 🚀 Como executar o projeto

1. Clone o repositório.

2. Abra o Android Studio e selecione **Open**.

3. Selecione a pasta do projeto clonado.

4. Aguarde a sincronização do Gradle.

5. Inicie um emulador Android ou conecte um celular ao computador.

6. Clique em **Run ▶** para executar o aplicativo.

## 👩‍💻 Projeto acadêmico

Desenvolvido para praticar programação Android com Kotlin e Jetpack Compose, explorando a criação de interfaces, navegação entre telas e gerenciamento de imagens.
